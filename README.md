# Журнал намерений для OpenCode

Плагин для OpenCode V2, который помогает не терять задачи, решения и запреты после `/compact`. Он ведёт отдельный журнал намерений пользователя и возвращает его модели после сжатия контекста — не заменяя штатную сводку.

- **Сохраняет детали:** «git не трогать», «файл назвать veg.txt», «проверку орфографии отложили».
- **Хранит локально:** отдельный журнал для каждой сессии, вне репозитория.
- **Не блокирует работу:** ошибки плагина не прерывают запросы и сжатие.

Упрощённый пример журнала:

```text
- [i1] Создать notes.txt с тремя фруктами — dropped
- [i2] Вместо фруктов три овоща в veg.txt; notes.txt удалить — done
  **why:** Пользователь передумал
- [i3] В veg.txt все названия строчными буквами — done
*Postponed: проверка орфографии в veg.txt*
```

## Подключение

Текущие проверки выполняются на OpenCode **2.2.0** с SDK 2.2.0. Нужны Git, Node.js и npm. Клонируйте репозиторий и соберите окно памяти:

```sh
git clone https://github.com/serge-masiutin/opencode-session-checkpoint.git
cd opencode-session-checkpoint
npm ci
npm run build
pwd
```

Добавьте полученный абсолютный путь в массив `plugins` файла `~/.config/opencode/opencode.json`, сохранив остальные настройки и плагины:

Добавьте пути в существующие массивы `plugins` и `instructions`, не заменяя другие пути. Если устанавливаете оба плагина, включите в каждый массив пути обоих.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["/absolute/path/opencode-session-checkpoint"],
  "instructions": ["/absolute/path/opencode-session-checkpoint/docs/agent-instructions.md"]
}
```

Отправьте сообщение в новой сессии. В `~/.local/share/opencode/session-notes/<ID сессии>/intent.md` появится запись. Для отключения удалите из `plugins` только путь к этому плагину.

### Инструкции для агента

Подключите [готовые правила](docs/agent-instructions.md) через `instructions`, как в примере. Вместо этого можно скопировать их в ваш `~/.config/opencode/AGENTS.md` или проектный `AGENTS.md`. Не подключайте оба варианта одновременно; сохраните остальные пути и правила.

Если копируете правила в `AGENTS.md`, не добавляйте путь этого файла в `instructions`; если уже добавили — удалите только этот путь.

Плагин сам добавляет инструменты, краткое напоминание о журнале, список доставленных записей без сути и подсказки перед сжатием и после него. Готовый файл задаёт рабочие правила: когда обновлять статус, как читать исходный текст и почему нельзя обращаться к очереди напрямую. При отключении плагина удалите также его путь из `instructions`, если добавляли его туда.

## Как работает

1. Когда сообщение включено в подготовленный запрос модели, плагин сохраняет его полный текст и создаёт заготовку записи. Постановка в очередь сама по себе не создаёт ни запись, ни файл промпта. Это граница подготовки запроса, не подтверждение успешного ответа провайдера.
2. Плагин просит модель дописать суть, причину, решение и статус через `intent_update` и `intent_note`: при новой задаче, смене решения, запрете, блокере и завершении этапа, а не после каждого действия.
3. Перед сжатием журнал передаётся модели, которая пишет штатную сводку. Её шаблон и результат плагин не меняет.
4. После каждого сжатия модель один раз получает журнал: открытые записи полностью, остальные — по одной строке.

Когда размер контекста по данным последнего ответа модели достигает **300 тыс. токенов**, плагин напоминает дописать важное и запрашивает штатное сжатие. У подагентов отдельного журнала нет.

При откате сообщений их записи закрываются как `dropped` на следующем запросе, включая откат после сжатия по сохранённой staged-границе.

### Обновление со старой версии

Текущая версия предназначена для новых сессий; старые журналы не поддерживаются. После обновления начните новую сессию.

## Хранение и расход контекста

Журналы находятся в `~/.local/share/opencode/session-notes/`: `intent.json` — данные, `intent.md` — читаемое представление подтверждённых записей, `prompts/` — полные доставленные сообщения. При загрузке плагина удаляются каталоги сессий без изменений **15 дней и более**. Ошибки записываются в `plugin.log`.

Команды и вывод инструментов отдельно не собираются. **Сообщения пользователя сохраняются целиком, без автоматического удаления секретов:** если вставить ключ в сообщение, он попадёт и в локальную копию.

Постоянная инструкция и инструменты добавляют, по предварительной оценке, около **600 токенов на запрос**. Сам журнал при сжатии добавляется сверх этого объёма. Меняющиеся подсказки стоят в конце запроса, чтобы сохранять стабильный префикс для кэша провайдера.

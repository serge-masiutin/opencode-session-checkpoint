# Работа с репозиторием

- Сохраняй поведение плагина вне задачи. Основные файлы: `runtime.mjs` — хуки и инструменты, `journal.mjs` — хранение.
- Проверяй изменения командой `npm test`; интеграционные сценарии — в `docs/development.md`. Платные вызовы моделей требуют отдельного согласования.
- Не добавляй журналы сессий, пользовательские сообщения, credentials и конфигурацию с секретами в репозиторий.

## Git и GitHub

- Для GitHub используй только `bin/gh`: он проверяет аккаунт `serge-masiutin` и задаёт репозиторий `serge-masiutin/opencode-session-checkpoint`.
- Сохраняй локальные Git identity и SSH в `.git/config`: `Serge Masiutin <sergeimasiutin@gmail.com>`. Не меняй глобальную авторизацию, Git/SSH и другие проекты.
- Credentials находятся только в `gh/hosts.yml` внутри Git-каталога, с правами `600`; каталог — `700`. Не выводи их содержимое.

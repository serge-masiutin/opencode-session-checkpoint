# Панель памяти: прототип и нативная интеграция

Прототип `preview/` — вымышленные данные, изменения только в памяти страницы. Нативная панель `gui/` уже реализована на публичном SDK и собирается в `dist/gui-experimental.cjs`; пакет экспортирует `./gui-experimental`. Рабочая установка не изменялась.

Из корня репозитория:

```sh
npm --prefix preview ci --ignore-scripts
npm --prefix preview run check
npm --prefix preview test
npm --prefix preview run build
npm --prefix preview run dev
```

Адрес: <http://127.0.0.1:4317>. Нужен Node.js 22.18 или новее; проверено на 22.23.1. Сервер слушает только localhost.

## Контракт интерфейса

- Интерфейс — английский; записи, решения и промпты сохраняют исходный язык.
- Без рекламных блоков, onboarding и повторяющихся объяснений.
- Список → детали → исходный промпт → правка. В узкой панели — переход назад вместо двух колонок.
- Исходный промпт доступен только для чтения. Правки имеют отдельную историю.
- Ошибка или конфликт оставляет черновик в форме. Переход к другой записи во время правки блокируется с сообщением.
- Переключатели тем, ширины и ошибок — инструменты песочницы, не элементы будущего плагина.
- Статус выбирается компактным меню, без системного `select`. В Desktop нужен штатный `ctx.ui.Menu`.

## Нативная панель

- `gui/index.tsx` регистрирует боковую вкладку Memory, команду и пункт меню на публичных `Panel`, `Command`, `MenuItem`, `Style`; `gui/panel.tsx` — список, детали, поиск, фильтры, чтение промпта по требованию, правка, история `userEdits` и отдельные `notes`/блокеры. Только штатные `ctx.ui`, тема хоста, английский интерфейс; содержимое записей не переводится.
- Заметки — карточки с бейджем вида и кнопкой dismiss; бейдж блокера окрашен в danger, отложенного — в warning. Dismiss удаляет только заметку уровня сессии, записи и промпты не трогает. Пояснения к заметкам относятся ко всей сессии, а не к отдельной записи.
- Статистика открывается icon-кнопкой в тулбаре panel section и показывает в диалоге активность агента (записи в журнал, выдачи модели, восстановления после сжатия, сводки, напоминания о давлении, правки пользователя, время последней записи/выдачи) и состояние памяти (открытые/все/с решениями/ждут сути/откатанные записи, число заметок).
- Черновики хранятся только в памяти окна (`Map` по scope сессии), исходные промпты не дублируются. Scope включает server/location сессии; при переключении сессии панель перемонтируется, поздние ответы отменяются через `AbortController`, подписка `updated` снимается в `onCleanup`.
- Ошибка или конфликт сохраняет черновик, показывает сообщение и обновляет снепшот для явного `Use current version`. Откатанные записи read-only.
- Статус — компактное штатное `ctx.ui.Menu` (в прототипе проверено 160×116 px, стрелки/Enter, возврат фокуса).

## Backend и RPC

- `rpc.ts` — контракт `local-session-checkpoint.memory`: `list`, `prompt`, `edit`, `dismiss`, `stats`, событие `updated`. Входы — строгие через Standard Schema (лишние поля отклоняются; JSON Schema в 2.2.0 их молча удаляет, `pattern` запрещён). Выходы — JSON Schema. Заметки несут `id`/`at`.
- `memory-api.mjs` — представление записей, поиск по сохранённым промптам, вызовы того же `Journal`, что и инструменты модели. `prompt` отдаёт только один текст по запросу; `dismiss` удаляет заметку и возвращает оставшиеся; `stats` отдаёт счётчики использования и состояние памяти.
- `memory-rpc.ts` — регистрация RPC, проверка location/parentID сессии, перевод ошибок, уведомление `updated` после сохранения и dismiss.
- `journal.mjs` — `inspect`, `edit` с SHA-256-версией записи, `userEdits`, `userCorrections` попадают в обычный контекст без отдельного хода модели; откатанные записи указаний не дают. Заметки получают `id`/`at`; `dismissNote` удаляет только заметку, записи и промпты не трогает; `noteServed`/`touchWrite` считают выдачи журнала модели и записи в него; старые файлы без `usage` читаются с нулевыми счётчиками. `runtime.mjs` изолирует сбой регистрации GUI от хуков/инструментов и фиксирует выдачу журнала: обычный контекст, восстановление после сжатия, сводка.
- Сборка: `npm run check`, `npm run build` → `dist/gui-experimental.cjs` (игнорируется Git).

## Границы этапа

Solid 1.9 используется потому, что GUI SDK OpenCode работает на Solid. Прототип использует свои HTML/CSS только для согласования вида; нативная панель использует публичные `ctx.ui` и токены хоста. Импортировать внутренний `@opencode/ui` нельзя.

Проверено в отдельном Desktop 2.2.0 с тестовыми каталогами и локальным провайдером: панель открылась, запись сохранилась через настоящий RPC, меню статусов 160×116 px, история показывает авторство, исходный промпт неизменен. Это ручная выборочная проверка, а не заявление о полной Desktop-совместимости.
